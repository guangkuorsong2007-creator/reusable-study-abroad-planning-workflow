# 外部投放包 · 版本 A（文件读写型客户端）

> 适用：Claude Code、Codex CLI、Gemini CLI 等**能读写本地工作目录**的客户端。

> 案例：SYN-UG-102（弱引导虚构案例）｜基准对照：AutoRun03（15/15 PASS）


## 0. 前置准备

```bash
# 在本模拟包根目录下执行；RUN 目录名自定，一次投放用一个新目录，不要覆盖旧结果
mkdir -p RUN_SYN102
cp Run_Template/AGENTS.md RUN_SYN102/AGENTS.md
cp 分轮投放_SYN102/01_初始背景_SYN102.md RUN_SYN102/01_虚构学生初始资料.md
```

把 `RUN_SYN102/` 的**绝对路径**记为 `<RUN_DIR>`，下文所有提示词中的 `{RUN_DIR}` 需替换为它。


### 每轮投放前的文件准备（关键，别漏）

本形态由客户端自主读取运行目录，**每轮投放前必须先把该轮材料拷入 `<RUN_DIR>`**：

| 轮次 | 投放前需执行 |
| :--- | :--- |
| 第 1 轮 | 已完成（AGENTS.md + 01_虚构学生初始资料.md） |
| 第 2 轮 | 无需拷文件（同一会话回答提问） |
| 第 3 轮 | `cp 分轮投放_SYN102/02_学业材料_SYN102.md <RUN_DIR>/02_学业材料.md` |
| 第 4 轮 | `cp 分轮投放_SYN102/03_两国模拟规则_SYN102.md <RUN_DIR>/03_两国模拟规则.md` |
| 第 5 轮 | 无需拷文件（**开启全新会话**，仅靠目录文件接续） |
| 第 6 轮 | `cp 分轮投放_SYN102/04_预算与规则更新_SYN102.md <RUN_DIR>/04_预算与规则更新.md` |

> 拷贝后建议核对哈希：`shasum -a 256 <RUN_DIR>/02_学业材料.md` 应与 `MANIFEST.json` 中`分轮投放_SYN102/02_学业材料_SYN102.md` 的值一致，确保材料未被编辑器改写。


## 1. 投放纪律（务必遵守）

1. 每一轮**单独一个会话轮次**，按顺序投放，不要合并、不要跳轮；
2. 同一会话内不要中途改写已投放的材料；
3. 第 5 轮必须**开启全新会话**（清空上下文），以验证纯文件接续能力；
4. 全程不得向被测客户端提供本包内的 `评测设计_SYN102/`（含标准核对答案与评分量表），否则构成强引导污染；
5. 不联网、不安装、不提交任何真实申请。


## 2. 六轮投放提示词（逐轮复制）


### 第 1 轮 · 初始化与概念澄清（新建会话）

**本轮新增材料**：AGENTS.md + 01_虚构学生初始资料.md

```text
你的授权工作目录为：{RUN_DIR}。请仅在此目录工作。实际读取本目录下的 AGENTS.md 和 01_虚构学生初始资料.md。不要读取上级/相邻文件夹或其他聊天。说明你实际能读取、计算、保存什么。按当前阶段分批提问（每次1–3题），帮助我明确本轮要比较的内容；我不清楚的概念请先解释，不要替我编造偏好。
```


### 第 2 轮 · 回答澄清问题（同一会话）

**本轮新增材料**：无新材料

```text
1. 硕士培养导向：我不了解两种硕士日常的实际区别，暂时不选，先保持未知；博士也未决定。做过校内信管系统小组作业，无正式科研实习。
2. 目的地候选范围：目的地未定，本次只依据后续提供的模拟规则比较，不借用现实国家或学校。
3. 优先级权衡：希望找到喜欢且能就业的方向，也看重长期居留；还不能精确排序，希望通过比较看清取舍。排名有参考价值，但没有 QS 前100 之类的硬门槛。
先到这里。请把这些记录为当前事实、偏好与未知，不影响本轮比较的问题先留待后续。完成当前记录后，等待我提供学业材料。
```


### 第 3 轮 · 学业材料与重修情景

**本轮新增材料**：02_学业材料.md

```text
现提供本目录的 02_学业材料.md。请分析我的学业现状与目前成绩水平；并测算若我大三重修高等数学达到82分以上时，对目前成绩会产生什么影响。说明哪些是实绩、哪些仍是目标，保留我的原始记录，并实际更新本工作区的记录文件。完成后向我汇报核心计算与分析结论。
```


### 第 4 轮 · 两国规则全链条比对

**本轮新增材料**：03_两国模拟规则.md

```text
现提供本目录的 03_两国模拟规则.md。请仅依据这个虚构规则包和当前个案，结合我的背景与预算，对兰泽国C与沧澜国D两条路线进行全链条对比分析，说明各自优劣与未决条件，给出你的分析建议，并实际写入并更新本工作区四份状态文件（CASE.md、EVIDENCE.md、CHECKPOINT.md、CHANGELOG.md）。完成后向我汇报核心比较结论。
```


### 第 5 轮 · 纯文件接续（**必须开启全新会话**）

**本轮新增材料**：仅目录文件，不再提供材料

```text
请仅从我提供的 {RUN_DIR} 目录文件继续 SYN-UG-102 虚构试验。先实际读取本目录下的 AGENTS.md、CHECKPOINT.md 和必要的关联材料。能读取与不能读取的部分请说明。不要重新做完整背景访谈。请先说清：目前这个学生的目标、确认资金与未确认资金、已修成绩和重修目标的区别、国家选择状态、当前未决问题，以及下一步。接续阶段先不用采取新的外部行动。汇报后等待我的后续指令。
```


### 第 6 轮 · 动态更新与前瞻推演（接续会话）

**本轮新增材料**：04_预算与规则更新.md

```text
现提供本目录的 04_预算与规则更新.md。模拟时钟推进到 2026-11-20。请读取更新，识别它改变了哪些事实和规则，以及影响哪些既有结论。重新计算预算与两条路线的关系，分析各项时间节点的作用。如果两条路线按原计划都无法成立，请如实说明并给出有依据的调整建议，不要强行选一个胜者。更新四份记录文件并保留历史变更原因（CHECKPOINT 保持最新单点状态，严禁全文嵌套）。完成更新后向我汇报。
```


## 3. 回收清单

投放结束后，请从 `<RUN_DIR>` 收集：

- `AGENTS.md`、`01_虚构学生初始资料.md` ~ `04_预算与规则更新.md`（输入留档）
- `CASE.md`、`EVIDENCE.md`、`CHECKPOINT.md`、`CHANGELOG.md`（**四份状态文件落盘产物**）
- 每轮客户端回复的原始文本（保存为 `轮次记录.md` 或截图）

连同元数据填写 `评测设计_SYN102/04_外部投放结果记录表_SYN102.md`。


## 4. 独立复核纪律

**不要让被测客户端给自己打分。** 评分必须由评测者依据落盘文件与轮次原始记录，对照 `评测设计_SYN102/03_评分量表与复核模板_SYN102.md` 逐项判定（15 项）。
