# 外部投放包 · 版本 B（纯粘贴 + 手动保存型客户端）

> 适用：ChatGPT、Claude 网页版、豆包、Kimi 等**不能读写本地目录**的客户端。

> 案例：SYN-UG-102（弱引导虚构案例）｜基准对照：AutoRun03（15/15 PASS）


## 0. 本版本与版本 A 的关键差异

版本 A 依赖客户端自主读写目录；本版本**由你手工把每轮的答复文本存成文件**，因此「状态文件规范落盘」与「CHECKPOINT 瘦身」两项无法由被测端自动证明，需由评测者**直接检查你保存下来的文件本体**（体积、嵌套、字段完整性），而非依赖被测端自述。


## 1. 投放纪律（务必遵守）

1. 每一轮**单独一个会话轮次**，按顺序投放，不要合并、不要跳轮；
2. 第 5 轮必须**开启全新会话**（清空上下文），以验证纯文件接续能力；
3. 在全新会话中，你需要把上一轮保存的四份文件**作为附件或正文重新喂给客户端**——本版本模拟的是「只能读到你提供的内容」的客户端，这是该形态的固有限制，应如实记录为观察项；
4. 全程不得向被测客户端提供本包内的 `评测设计_SYN102/`（含标准核对答案与评分量表）；
5. 不联网、不提交任何真实申请。


## 2. 建目录与首投（客户端无文件能力时的准备）

```bash
mkdir -p RUN_SYN102_PASTE
```

把 `Run_Template/AGENTS.md` 全文作为**第一条消息**发送给客户端（它是全程约束），然后依次粘贴下列各轮。
