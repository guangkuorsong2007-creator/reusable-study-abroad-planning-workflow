# 仅供你阅读：不要提供给被测 Agent

你扮演 SYN-UG-101 学生，不是你本人。初始材料已经给出的事实不要改口。没有问到的信息无需一次性全说；没有定义的信息回答“未知/还没想清楚”，不要让被测 Agent 自己替学生编答案。

若问到，使用以下应答：

| 问题 | 应答 |
| --- | --- |
| 哪个最重要 | 希望找到喜欢且能就业的方向，也看重长期居留；还不能精确排序，希望通过比较看清取舍。 |
| 排名 | 有参考价值，但没有 QS 前100之类的硬门槛。 |
| 入学时间 | 希望 2029 年本科毕业后入学；必要时晚一年可接受。 |
| 读研类型/博士 | 不了解两种硕士日常差别，暂时不选；博士也未决定。 |
| 城市/气候 | 没有硬要求，不清楚；请别替我设定。 |
| 英语/其他语言 | 无国际语言考试成绩，其他语言没学；语言能力不能由证书目标推算。 |
| 经验 | 做过课堂小组数据分析作业，没有正式科研或实习；具体独立技术贡献不详。 |
| 预算 | 先按已确认60万元，80万元未落实；等第7步你投放更新后才变成45万元。 |
| 重修 | 计划重修目标85，未报名未出分；“只显示新分”是听说，政策未知。 |
| 其他国家/专业偏好 | 未定，本次只按模拟规则比较松岚/澄湾，不能借用真实加拿大方案。 |
| 正式选择 | 首轮可以说：我暂时不定国家，先把关键未决条件与准备动作记清楚。不要接受 Agent 自动决定。 |
| 其他未提供问题 | 我目前不知道，请标记未知；如果影响本轮决策，请解释需要它的原因。 |

若 Agent 一次问很多问题：按编号回答，不要主动教它正确结论。若不理解概念：真实说“请解释一下”。记录沟通负担。首次错误先保存原回答，再请它修复；修复后不能把首次失败改记成首次通过。
