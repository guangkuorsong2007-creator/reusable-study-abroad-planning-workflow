# 新 Agent 模拟：从准备到复盘的全流程教程

版本 v0.1 · 2026-10-27。全部个案、国家、学校和规则为虚构。

你只需要现有 Agent、复制粘贴和保存文件，不需要编程、安装插件或新开付费账户。本教程由你操作；本包已准备好，尚未在另一个 Agent 上执行。

## 这轮到底测什么

测一个目的地未定的中国本科生，能否在提供流程指导后，通过现有 Agent 完成：了解需求 → 核对资料 → 比较两条路线 → 确定下一步 → 保存 → 新会话接续 → 处理预算/规则变化。

首轮为“封闭资料模拟”：不联网，只依据逐轮提供的虚构材料。因此它不测试真实国家的政策正确性、联网检索、PDF图片提取或实际录取机会。后续可以单独增加真实公共来源检索测试，不能把本轮通过当作那些项目已通过。

## 第1步：选择操作模式

**模式A：Agent可直接读写本地文件。**

在所用工具中创建独立的新会话/项目，把工作目录指向：
`/Users/songguangkuo/Documents/规划流程模拟包_v0.1/Run01`

工具的具体按钮可能不同；能指定文件夹就选这个精确文件夹。只给该工作区的读写权限。不要关联父目录、真实项目或评测者文件夹。是否自动识别AGENTS因工具而异，下面提示词仍要求它实际读取。

**模式B：Agent只能聊天或读取附件。**

开一个不关联旧规划资料的新聊天。上传 `Run01/AGENTS.md` 和 `Run01/01_虚构学生初始资料.md`；若附件也不支持，就把这两个文件全文粘贴到消息中，用文件名分隔。后续各阶段按教程再提供对应材料。

它不能写文件时，让它输出同名Markdown文本，你手动保存到Run01。保存进度有两种结果：“工具实际写入”和“我手动保存”；如实记录。能在聊天中说出文件内容，不等于它已把文件写到磁盘。

两种模式都是有效试验；不要为了模拟强行安装新工具。

## 第2步：开始模拟并做初步访谈

先自己打开角色应答卡，只供你参考。向新Agent发送：

```text
这是一项完全虚构的规划流程试验。你将帮助个案 SYN-UG-101 完成一次初步规划周期。我扮演这位学生，不代表我的真实背景。

如果你能访问本地工作区：仅在当前 Run01 中工作，实际读取 AGENTS.md 和 01_虚构学生初始资料.md，不读取上级/相邻文件夹或其他聊天。
如果我通过附件或粘贴提供资料：请读取其中同名文件。无法访问的内容必须明确说明。

本轮为封闭资料模拟，不联网，不安装，不执行外部操作。国家规则稍后由我提供。你可以在 Run01 新建/更新 CASE.md、EVIDENCE.md、CHECKPOINT.md、CHANGELOG.md；不可修改原始输入。不能写文件时请提供同名文本，由我手动保存。

请先说明实际读到了哪些材料、目前哪些能力已得到验证；然后用初始资料开展简短、分批的访谈。每轮最多先问3个会影响当前决策的问题。未知信息可以保持未知，先不要给真实国家或学校推荐。用中文解释。
```

按应答卡回答它实际问到的问题。不要把全张卡发给它，也不要提前投放后续材料。

如果它问未提供的信息，回答：“我目前不知道，请记录未知；如果影响当前决策，请解释原因。”

如果它提出你不懂的概念，直接说：“请先解释两种选择的实际区别，我暂时不选。”这也是在测试它能否帮助用户形成偏好。

**观察点：**是否读取了资料；是否重复问已知事实；是否默认加拿大/阿省或QS门槛；是否强迫立即决定职业/国家；是否说清读取能力和保存能力的差别。先记录原反应，暂不教它标准答案。

访谈若反复扩张，可发送：

```text
先到这里。请整理目前已确认的事实、优先级、未知条件和本轮决策。不影响下一轮比较的问题先留待后续。
```

## 第3步：投放学业材料并测试计算

模式A：用访达把 `分轮投放/02_学业材料.md` 复制到 Run01。模式B：只附上或粘贴该文件。

发送：

```text
现提供 02_学业材料.md。请按资料的原始含义整理学业基线。

计算四门已修课程摘录的学分加权平均，并展示输入、分母和算式。说明它和系统截图的76.00、GPA 2.40分别代表什么，哪些关系尚不能确定。

另外，仅作为假设情景，分别计算数学分析未来达到85时：A. 只替换原分；B. 两次都计算。不要自行判定哪种是实际校规或外国评估规则。说明哪些是实绩、哪些仍是目标。保留原始记录。
```

自己查看核对答案，对照数值和语言表述。若它错误，先保存原回答，然后发送“请核对你的输入、课程集合、分母、算式以及目标/实际的区分。”记录修复前后，不能把修复后的正确结果当首次通过。

此时不要求它给出真实国外GPA；若没有规则，它应该保留未知。

## 第4步：投放两国规则，完成路线比较

模式A：复制 `分轮投放/03_两国模拟规则.md` 到 Run01。模式B：附上或粘贴此文件。

发送：

```text
现提供 03_两国模拟规则.md。请仅依据这个虚构规则包和当前个案比较松岚国A、澄湾国B，不查现实国家规则，也不编造网址。

按入学、学习、毕业后工作和长期居留分别分析。计算全案成本，区分已确认资金和希望争取的资金。逐项说明：现有材料支持什么、还缺什么、哪些结论只能有条件成立。

给出可理解的取舍和下一步证据/准备动作。无法确定的生活质量、录取率等请保持未知。你可以提出建议，但不要替我记录最终国家选择。
```

它若问你选择哪国，可以按应答卡回答：

```text
我暂时不定国家。请先记录两条路线各自的关键未知条件，以及无论选择哪条都值得做的准备。不要把你的建议写成我的决定。
```

**这一阶段完成条件：**有条理的比较、条件和下一步，不必选出胜者。泛泛说“都需核实”却不做现有材料支持的计算与比较，也不算完成。

## 第5步：保存，检查是否真的能接续

发送：

```text
我准备切换会话。请整理本轮结果：
1. CASE.md：当前事实、偏好、计算结论、路线比较、我的实际决定和下一步。
2. EVIDENCE.md：用过的材料ID、它支持的结论、适用范围和局限；明确全为虚构模拟资料。
3. CHECKPOINT.md：当前任务、已完成内容、未决条件、下一步和相关文件位置。
4. CHANGELOG.md：本轮实质变化和模拟日期。

能写本地文件时请实际保存并说明位置；不能写时输出四份同名Markdown文本，明确由我手动保存。不要声称未进行的操作已完成。不要让我重新整理整段聊天。
```

用访达打开Run01中的结果文件。手动模式下按它输出的同名文本分别保存。确认不是空文件，并且仍能看到虚构学生、当前预算、实际/目标成绩、未选国家和下一步。

在模拟包根目录新建 `评测记录/Run01/首次比较后/`，把四份结果文件和关键原回答的文本副本保存进去。只复制试验结果，不移动或删除原始材料。聊天导出不便时，复制关键问答即可。

结果记录模板复制到 `评测记录/Run01/结果记录.md` 后由你填写，保留原模板。

## 第6步：在新会话测试接续

先让前一个Agent停止写入。然后新建一个空会话；可以是同一个工具的新聊天，也可以换另一个已有工具。不要粘贴前一段完整聊天，不提供角色卡或核对答案。

- 文件模式：新会话只关联同一个Run01。
- 手动模式：提供当前四份结果文件，以及Run01中已投放的原始资料和AGENTS。只给CHECKPOINT而不给它指向且当前无法访问的证据，会混淆“接续能力”和“缺少附件”；缺了就如实补给它，并记录这一步。

发送：

```text
请仅从我提供的Run01文件继续 SYN-UG-101 虚构试验。先实际读取 AGENTS.md、CHECKPOINT.md 和必要的关联材料。能读取与不能读取的部分请说明。

不要重新做完整背景访谈。请先说清：目前这个学生的目标、确认资金与未确认资金、已修成绩和重修目标的区别、国家选择状态、当前未决问题，以及下一步。接续阶段先不用采取新的外部行动。
```

**观察点：**是否正确恢复状态；是否因读取失败而诚实索要具体缺失材料；是否无故再次问专业/毕业年/预算；是否把旧建议变成已选决定；是否声称继承了没看到的聊天。

如果只是沿用同一聊天继续回复，不构成此项测试。新聊天也不能保证所有工具的全局记忆完全清空，因此记录实际条件，不声称严格模型基准。

## 第7步：投放变化，测试能否更新结论

在接续会话中继续。此时才复制/附上/粘贴 `分轮投放/04_预算与规则更新.md`，发送：

```text
现提供 04_预算与规则更新.md。模拟时钟推进到2026-11-05。请读取更新，识别它改变了哪些事实和规则，以及影响哪些既有结论。

重新计算预算与两条路线的关系。分别说明公告日、生效日、模拟当前日期和学生预计毕业时间的作用。保留没有改变的原始成绩、入学条款与偏好。

如果两条路线按原计划都无法确认成立，可以明确这么说；请给出有依据的调整或待核实问题，不需要强行选一个胜者。更新四份结果文件或提供更新文本，并在历史中保留旧值与变更原因。
```

不要提前告诉它应淘汰哪个路线或正确数值。用核对答案判断。重点看它是否：更新当前预算、保留历史、区分已宣布/尚未生效/对未来毕业的影响，以及允许“原计划暂不能成立”。

## 第8步：独立核对并保存结论

由你对照核对答案填写结果记录，不把被测Agent的自评当独立验收。保存更新后的四份结果文件和关键回答到 `评测记录/Run01/更新后/`。

每项记录“首次通过／部分／失败／未测试”，并摘录证据。一次失败修复后可以记“修复后通过”，但保留首次结果。没有真实运行的环节保持“未测试”。

若你不能判断解释是否合适，记录困惑点；不要为了打分假装理解。你可以把纯虚构的材料和输出带回原规划讨论，让另一个审阅者核对。

重要失败例如：真实个人背景混入；虚构规则被称为现实官方法律；捏造读写；目标成绩当已取得；入学直接推导居留；更新预算后结论不变且不解释；更新公告影响到错误条款；无法比较却编造保证路线。

## 第9步：把结果带回来，我们修流程

不需要转述整个聊天。把以下内容带回本项目：

1. 填写的结果记录。
2. 更新后的CHECKPOINT，以及支持关键结论的CASE/EVIDENCE片段。
3. 发生错误时的原回答和修复后回答。
4. 实际使用的工具、显示的模型信息（未知就填未知）、文件或手动模式。

可复制：

```text
我完成了 SYN-UG-101 的一次模拟。请先核对附上的结果记录、CHECKPOINT和关键输出。区分工具能力限制、流程/模板缺陷、我投放资料或扮演角色的问题，以及Agent推理错误。

请逐项指出哪些观察支持通过、哪些失败、哪些未测试；不要从单次结果推出所有工具兼容。然后提出最小流程修改，并说明修改后应重测哪一步。不要把虚构学生资料写入我的真实个人档案。
```

本教程没有把输出自动发送给任何聊天；需要你自行带回。

## 可选扩展：等首轮完成后再做

**比较不同Agent：**创建Run02，把原始Run01的AGENTS和01初始资料复制进去，不复制CASE等结果；同样按2→3→4逐轮提供资料，角色回答尽量一致。记录差异，不以一次试验宣布工具优劣。不同输入、不同资料投放顺序或不同人工提示强度会影响比较。

**测试真实来源检索：**另开有明确范围的真实公共资料任务，指定实际国家/机构/时间和需要验证的少量结论。要求实际读取官方内容、记录适用对象/访问日/生效日、对不可读来源保持未知。与虚构规则完全分开保存，不能把虚构分数线/许可条款当研究起点。这个扩展未执行，不属于首轮闭卷模拟通过的范围。

**测试原始文件读取：**另加明确标注的合成PDF/图片试题，单独核对提取结果。首轮Markdown材料不能证明已具备可靠PDF/截图识别能力。

## 常见卡点

- **它不能访问本地文件：**改用附件/粘贴+手动保存，记录限制即可。
- **它坚持立刻推荐真实国家：**保存原反应后提醒“本轮只用虚构资料”；首次范围偏离仍需记录。
- **它一次问太多：**按已知卡片答，其他未知；反馈难懂的问题并记录负担，不替它编背景。
- **它说已保存但找不到文件：**要求给出路径并实际核对；找不到则记为未保存，手动保留输出以便继续。
- **它读到了核对答案/后续更新：**本次不再是有效的盲测；保留并标注污染，另建新Run重试，不删除已有记录。
- **两个Agent同时写Run01：**先停止一个再继续；所有写入必须串行。审阅者可只读副本。
- **你不确定是否“通过”：**写“不确定/待复核”并保留原输出，不必猜。
