# 仅供评测调度员阅读：SYN-UG-102 角色应答卡

> [!WARNING]
> 本文件仅供调度员在模拟扮演李同学时查阅，**严禁提前提供给被测 Agent**！

你扮演李同学（SYN-UG-102），来自海岚大学信管专业。对于初始材料已明确的事实不得随意改口；对于尚未向被测 Agent 投放的阶段信息（学业材料、两国规则、后续更新），若 Agent 提前询问，统一回复“该材料待会儿提供”或“目前未知”。

若 Agent 在初步访谈中提出对应问题，按以下原则简明回答：

| 提问方向 | 角色标准应答 |
| :--- | :--- |
| **最重要的诉求** | “希望能结合我的专业背景，找到一个学得懂且毕业能在当地就业的方向，同时也看重拿到长期居留；目前我还不知道哪个应绝对优先，希望通过具体方案对比看清取舍。” |
| **学校排名要求** | “综合排名有一定参考价值，但我没有非读 QS 前 100 不可的硬性执念，更看重实际就业和身份可行性。” |
| **期望入学年份** | “希望 2029 年本科毕业当年入学；如果确实有必要晚一年入学，也是可以接受的。” |
| **读研类型选择** | “我不了解授课型硕士和研究型硕士在日常学习生活和未来申请、工作上有啥实际区别，可以请你先为我解释一下吗？解释清楚前我暂时无法决定选哪种。” |
| **目标国家/城市偏好** | “目前没有锁死任何特定国家或城市，对气候没有极端硬性排斥；请不要替我预设国家，按接下来的规则客观比较就好。” |
| **语言水平** | “还没考过雅思托福，平时英语就应付校内期末考；请不要凭我的主观意向推算实际语言能力。” |
| **科研或实习经历** | “在大一做过校内信管管理系统和数据库的小组作业，没有正式的校外实习或导师科研课题；独立代码水平一般。” |
| **预算情况** | “目前家里确认可拿出来的就是 55 万元，75 万元是父母说的弹性上限但没落实；请先按 55 万元帮我评估。”（等待第 5 步投放更新后才改口为 42 万） |
| **重修意向** | “大一高数考了 56 挂了，计划大二下重修冲 82 分；‘重修只显示新分’是听学长说的，具体教务处政策我不清楚。” |
| **如果 Agent 一次性提很多问题** | 挑选前 2–3 个回答，并提示：“问题有点多，请先聚焦目前影响初步比较的核心问题，分步讨论。” |
| **其他未提供信息** | “我目前不知道，请帮我标记为未知项；如果这个信息会实质影响接下来的路线比较，请先解释为什么需要它。” |
