# 虚构学生初始资料（占位模板 · 案例中立）

本文件是**占位模板**，不绑定任何具体案例。正式投放时，请将当轮案例的初始背景材料（如 `分轮投放_SYN102/01_初始背景_SYN102.md`）**整份复制覆盖**本文件。

覆盖后的文件必须满足：

1. 抬头标注案例编号与"完全虚构"字样；
2. 载明模拟日期（模拟时钟，非现实日期）；
3. 明确区分「家庭已确认资金」与「希望争取但未落实的上限」——只有已确认金额可作硬约束；
4. 明确写出"不假定奖学金或兼职收入"（如该案例适用）；
5. 明确声明尚未提供的材料（如成绩单、课程表、语言成绩），避免规划助手擅自假设已具备；
6. 指明沟通语言与本轮期望的产出范围。

> ⚠️ 严禁在此文件内写入任何真实申请人的姓名、院校、成绩或财务信息。本产品库所有投放材料均为合成数据。
