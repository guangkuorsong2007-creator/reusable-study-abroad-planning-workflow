# 面向多申请人的可复用留学规划工作流程 (Reusable Study Abroad Planning Workflow)

本项目是一套**解耦、模块化、可复用且高度严谨**的 AI 辅助硕士申请—海外就业—长期居留全流程规划体系。通过规范化的四状态文件结构、分步引导协议与标准化评测指标，确保不同背景申请人在多轮交互与跨 Agent 工具接续中，均能获得精准、自洽、且具前瞻抗风险能力的规划方案。

---

## 核心设计理念与架构

### 1. 核心理论：三阶段递进模型
- **阶段一：学业与背景现状精算**（学分加权均分、非数值课程隔离、不及格在档与重修提分测算、先修课缺口诊断）；
- **阶段二：多维约束交叉过滤**（预算全口径台账、语言学习成本与排期、意向国院校梯度匹配）；
- **阶段三：毕业后长效发展衔接**（工签法定条件与时效、工签对居留政策缺口自识别、前瞻政策冲击压力测试）。

### 2. 状态架构：四核心文件解耦
每一个规划会话运行实例（如 `Run_Template/`）均遵循四文件架构：
- `CHECKPOINT.md`：极简上下文锚点（严格 $\le 4,000$ 字节，杜绝递归膨胀，仅包含当前阶段、核心数字、关键断点与下一步指令）；
- `01_学生初始画像.md`：申请人背景与需求（实绩分、重修目标、预算与硬约束）；
- `02_选校与规划进展.md`：方案比对矩阵、课程目标、学制与移民链条；
- `03_会话流水日志.md`：多轮收发记录、决策节点与更新追踪。

### 3. 数据隔离与隐私保障
本工作流产品库**100% 采用合成数据与虚构案例（如松岚/澄湾/兰泽/沧澜等法条夹具）**，完全杜绝任何真实个人的档案、成绩单或隐私数据，具备完全的代码开源与产品化交付属性。

## 快速上手与评测验证

### 1. 运行现行弱引导自动基准测试 (AutoRun03)
在 `simulations/规划流程模拟包_v0.2/` 目录下：
```bash
python3 run_autorun03.py
```
该脚本将基于 `SYN-UG-102` 弱引导案例，自主完成加权均分、等级制课程隔离、重修情景建模、工签居留缺口发现与前瞻政策冲击应对，全过程捕获转录与快照并输出 15/15 指标独立复核报告。

> **可移植性**：脚本以**自身所在目录**定位包根（`WF_AUTORUN03_BASE` 可覆盖），仓库克隆到任意路径后均可直接运行，无需依赖固定绝对路径。

> **方法学提示**：`run_autorun03.py` 是**确定性重放器**——`CASE/EVIDENCE/CHECKPOINT` 正文以硬编码断言写入脚本，脚本本身不实际调用 LLM。15/15 是「产物 + 转录」的独立复核判定；实时智能体执行仅存在于 2026-10-28 的原始 AutoRun03 会话。

### 2. 外部客户端人工投放测试（v0.3 双版本投放包）

`simulations/规划流程模拟包_v0.3/` 提供两种投放形态，按目标客户端能力二选一：

| 形态 | 适用客户端 | 投放包 |
| :--- | :--- | :--- |
| **A · 文件读写型** | Claude Code、Codex CLI、Gemini CLI 等能读写本地目录者 | `Run_Template/03_外部投放包_文件读写版.md` |
| **B · 纯粘贴手动保存型** | ChatGPT、Claude 网页版、豆包、Kimi 等无文件能力者 | `Run_Template/04_外部投放包_纯粘贴手动保存版.md` |

两种形态共用同一套 SYN-UG-102 投放材料（`分轮投放_SYN102/`）与同一套六轮提示词，因此结果可横向对比。投放完成后，用 `评测设计_SYN102/04_外部投放结果记录表_SYN102.md` 记录观测元数据与 15 项复核判定。

> **独立复核纪律**：评分**不得**由被测 Agent 自行给出。必须依据落盘文件本体与各轮原始回复逐项核对；未实际投放的项目填「未测试」，不得填「通过」。
