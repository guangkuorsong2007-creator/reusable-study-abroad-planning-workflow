## 一、 验证背景与核心目的

在此前的验证中，模拟包在 v0.1（AutoRun01）与 v0.2（AutoRun02）阶段均取得了良好的内部合成表现。AutoRun02 复核报告显示 15/15 项检查点全部通过，并成功落实了 CHECKPOINT 解耦瘦身（-25.0%）、CASE 瘦身（-42.7%）、路径参数化及代号消歧等维护性成果。

然而，依据系统审计与交接规约，现有证据存在明显的**边界局限**：
1. **强引导解题偏差（Over-Prompting / Scaffolding）**：在 SYN-UG-101 中，测试提示词直接指引了加权分数的计算分子与分母、明确预设了重修情景 R1/R2 代号、明确告知了两国对比维度，导致测试更接近“执行明确指令”而非“自主诊断与规划”；
2. **单一案例过度拟合风险**：仅在一个合成案例（SYN-UG-101，14 学分摘录，松岚/澄湾规则）上运行过，缺乏对不同学科背景、不同学分结构、更具模糊性的输入场景的测试；
3. **异构客户端与真实用户未测**：尚未在不同商业客户端（如独立 Web 端、异构大模型底座）或由真实用户在无先验知识情况下投放。

**本方案的核心目的**：设计一个**低引导（Weak Guidance）、高真实感、包含非数值课程与复杂时序冲突的新合成案例（代号：SYN-UG-102）**，检验规划流程在用户输入模糊、缺乏解题手把手提示时，能否依然稳健地实现自主访谈澄清、学业客观加权、制度断裂识别、状态文件精简与新上下文纯文件恢复。

## 四、 虚构材料与标准答案设计 (内含精确数学验算)

### 4.1 学业摘录加权基线 (SYN-L11)

四门数值课程摘录（总学分 16.0）：
$$\text{分子} = 5.5 \times 56 + 3.5 \times 78 + 4.0 \times 84 + 3.0 \times 72 = 308.0 + 273.0 + 336.0 + 216.0 = 1133.0$$
$$\text{原始加权均分} = \frac{1133.0}{16.0} = 70.8125\% \quad (\approx 70.81\%)$$

- **非数值课程干扰项**：专业英语 1.5 学分，成绩为“合格 (Pass)”。
  - **红线**：分母绝不可计为 $16.0 + 1.5 = 17.5$（若误除以 17.5 得 64.74%，判定不及格）；
  - **红线**：绝不可将不及格的 56 分从分母中剔除（若误除以 10.5 得 78.57%，判定严重错误）。

### 4.2 重修情景测算 (假设高等数学重修考取 82 分)

- **情景 R1（仅替换原分 / Single Replacement）**：
  $$\text{新分子} = 1133.0 - 5.5 \times 56 + 5.5 \times 82 = 1133.0 - 308.0 + 451.0 = 1276.0$$
  $$\text{R1 加权均分} = \frac{1276.0}{16.0} = 79.75\%$$
- **情景 R2（两次均计入 / All Attempts Counted）**：
  $$\text{新分子} = 1133.0 + 5.5 \times 82 = 1133.0 + 451.0 = 1584.0$$
  $$\text{新分母} = 16.0 + 5.5 = 21.5$$
  $$\text{R2 加权均分} = \frac{1584.0}{21.5} \approx 73.6744\% \quad (\approx 73.67\%)$$

### 4.3 虚构路线比对 (初始状态：预算确认 55 万 / 争取 75 万)

| 项目与指标 | 兰泽国 C 项目 (SYN-C01) | 沧澜国 D 项目 (SYN-D01) |
| :--- | :--- | :--- |
| **学制与学位** | 2 年制，数据应用硕士 C | 1 年制，应用信息硕士 D |
| **入学门槛** | 本科评估均分 $\ge 75\%$，未给四门课独立口径 | 四门课原始均分 $\ge 70.0\%$ 且线性代数 $\ge 75$ |
| **当前学术匹配** | 摘录均分 70.81% 未达标，且全学程未知，待定 | 均分 70.81% 且线代 78，满足表面数值底线（但非保证录取） |
| **工签与居留衔接** | 工签 24 个月，居留需 12 个月工龄 $\rightarrow$ **顺畅覆盖 (+12月缓冲)** | 工签 12 个月，居留需 24 个月工龄 $\rightarrow$ **制度性断裂 (缺12月工签)** |
| **全案总支出** | 54 万元 (学费26+生活16+启动3+求职5+备用4) | 36 万元 (学费14+生活10+启动3+求职5+备用4) |
| **初始财务可行性** | 54 万 $\le 55$ 万（结余 1 万元，可行） | 36 万 $\le 55$ 万（结余 19 万元，可行） |

### 4.4 动态更新测算 (时钟推进至 2026-11-20，毕业时间预计 2029)

1. **家庭预算硬约束更新 (SYN-U11)**：上限降至 42 万元，无额外资助。
   - 兰泽国 C：总成本 54 万，超支 $54 - 42 = 12$ 万元 $\rightarrow$ **财务不可行**。
   - 沧澜国 D：总成本 36 万，结余 $42 - 36 = 6$ 万元 $\rightarrow$ 财务尚可。
2. **沧澜国未来工签法规公告 (SYN-D02)**：公告日 2026-11-15，生效日 2027-03-01。
   - 针对 2027-03-01 及之后毕业者，工签项目学制门槛由 $\ge 12$ 个月提升为 $\ge 24$ 个月。
   - 学生预计 2029 年毕业，1 年制 D 项目工签资格归零（0 个月）。
   - 居留所需 24 个月工龄彻底无从实现 $\rightarrow$ **工签与移民不可行**。
3. **最终结论**：**两案原计划均不可行**。建立调整池（寻找奖学金/廉价合规2年制/或重新评估国内规划）。
