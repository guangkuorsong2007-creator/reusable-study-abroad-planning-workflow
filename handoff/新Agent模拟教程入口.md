## 二、 投放纪律（务必遵守）

1. **只关联授权的运行目录**。例如从 `Run_Template/` 复制生成一个独立运行目录（`Run01`、`RUN_SYN102` 等），只让被测 Agent 访问该目录，**不要关联整个模拟包或本产品库**，否则它会看到评测材料。
2. **答案卡隔离**。`仅供评测者/` 与 `评测设计_SYN102/` 内的角色卡、标准核对答案与评分量表**不得交给被测 Agent**，否则构成强引导污染，使弱引导测试失效。
3. **不联网**。材料为全虚构封闭资料试验。真实国家政策检索、原始 PDF/图片提取另测。
4. **诚实记录能力边界**。无本地读写能力时用附件/粘贴与手动保存模式，并如实记录。
5. **不得让被测 Agent 给自己打分**。评分由评测者依据落盘文件本体与各轮原始回复，对照量表逐项判定。

## 三、 准备与投放

v0.3 投放包已内建完整操作步骤，**逐轮复制粘贴即可**，包括：

- 每轮投放前的文件准备表（形态 A）与逐字内联的材料正文（形态 B）；
- 六轮提示词，其中第 5 轮**必须开启全新会话**，用于验证纯文件接续的零遗忘能力；
- 手工保存清单与体积核验命令（形态 B）；
- 回收清单。

投放完成后，填写 [`04_外部投放结果记录表_SYN102.md`](../simulations/规划流程模拟包_v0.3/评测设计_SYN102/04_外部投放结果记录表_SYN102.md)，并把落盘文件副本与各轮原始记录归档至 `simulations/规划流程模拟包_v0.3/评测记录/外部投放_<客户端>_<日期>/`，最后在 [`../04_Evidence_Registry.md`](../04_Evidence_Registry.md) 登记一行。

## 四、 证据边界（沿用 v0.2 教程口径）

材料为全虚构封闭资料试验，不联网。静态算式与文件清单已核对，**未执行任何新的外部 Agent 试验**——外部投放须由用户实际执行后方可声称完成。请带回结果记录、更新后的 `CHECKPOINT.md` 和关键输出以复盘流程；**不要将虚构成绩写入任何真实个人档案**。

**形态 B 的固有局限**：无文件能力的客户端无法自行落盘，故「状态文件规范落盘」与「CHECKPOINT 瘦身」两项**无法由被测端自证**，须由评测者直接检查文件本体（字节数、是否嵌套旧全文、是否空文件），不可采信被测端自述。
