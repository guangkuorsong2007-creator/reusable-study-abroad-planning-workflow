1. `AGENTS.md`——治理规约与红线（**先读**，它约束你后续所有行为）；`00_Status.md`——当前阶段与未决事项。

3. `02_Roadmap.md`——版本演进路线（v0.1–v0.4 达成标准）；`03_Decisions.md`——架构决策流水（**WF-D001+** 为本库自有决策，WF-H* 为继承决策）。
4. `04_Evidence_Registry.md`——合成夹具索引与历次运行证据；`05_Session_Log.md`——分轮会话流水。
5. `simulations/`——全部基线资产：
   - `规划流程模拟包_v0.1/`——**冻结历史基线**（AutoRun01）；

## 三、 当前成熟度与证据边界（**最重要的一节，请勿跳过**）

- **已验证（内部合成环境）**：AutoRun01/02/03 三轮自动化基准运行，全部达成 15/15 量表通过；覆盖分轮问答、加权均分口径与条件计算、非数值课程隔离、挂科在档与重修情景分离、两国虚构规则比较、四文件落盘、纯文件接续零遗忘、预算收紧与前瞻政策推演。
- **15/15 的准确含义**：这是**「落盘产物 + 执行转录」的独立复核判定**，**不是**实时智能体评分，更**不是**普适准确率。`run_autorun03.py` 是**确定性重放器**（`CASE/EVIDENCE/CHECKPOINT` 正文以硬编码断言写入脚本），脚本本身不调用 LLM；真实智能体执行仅存在于 2026-10-28 的原始 AutoRun03 会话。
- **转录性质**：`transcript.json` / `transcript.md` 记录的是**调度层收发文本摘要**，不是底层完整网络调用流或无损原始交互转录。
- **哈希证明效力**：快照与模板哈希匹配证明的是**文件一致性与未篡改落盘**，不等同于技术层面的绝对上下文隔离、推理正确或零修复轮。
- **环境局限**：内部同工具环境、受指导、封闭虚构模拟；**不是**外部厂商客户端验收、不是真人用户体验验收、不是真实政策检索或 PDF/图片提取验收。逻辑与指令隔离，非操作系统沙箱。
- **尚未验证**：外部商业客户端（Claude Code / ChatGPT / Gemini CLI 等）兼容性、真实用户理解度与可用性、广泛国家规则覆盖与长期维护、商业需求/定价/交付支持。

## 四、 材料位置与保护

- **全部路径均相对本仓库根目录**，仓库克隆到任意位置均可直接使用；不存在跨库绝对路径依赖。
- `simulations/规划流程模拟包_v0.1/`、`v0.2/`、`v0.3/` 为**不可覆盖的冻结资产**：其产物、快照、manifest、输入材料与答案卡一律不修改、不删除。新测试必须使用新目录。
- **答案卡隔离**：`仅供评测者/` 与 `评测设计_SYN102/` 内的角色卡、标准核对答案与评分量表**不得交给被测 Agent**，否则构成强引导污染。
- **隐私红线**：本仓库全量为合成数据，严禁引入任何真实申请人的姓名、学号、真实就读院校、真实成绩单或真实家庭财务数据。复用模板只能用空白或合成内容。
- **Git**：本仓库已初始化 Git 仓库并完成入库（`LICENSE` 为 MIT）。**是否 commit / push 由用户决定**；不得擅自推送远程或发布。

## 五、 下一步与完成标准

**当前第一优先级是 v0.3 外部异构客户端验证**，且它需要**用户本人执行人工投放**（Agent 不得代替用户登录商业客户端）。投放包已就绪：

1. 用户按目标客户端能力二选一：`simulations/规划流程模拟包_v0.3/Run_Template/03_外部投放包_文件读写版.md`（形态 A）或 `04_外部投放包_纯粘贴手动保存版.md`（形态 B）；
2. 六轮提示词逐轮投放，第 5 轮**必须开启全新会话**；
3. 回收落盘文件与各轮原始记录，填 `评测设计_SYN102/04_外部投放结果记录表_SYN102.md`；
4. 归档至 `simulations/规划流程模拟包_v0.3/评测记录/外部投放_<客户端>_<日期>/`，并在 `04_Evidence_Registry.md` 登记一行。

**接续完成的标志**：报告实际可访问的材料与工具能力；正确恢复当前阶段、已完成工作与未决项；给出下一步的最小可执行动作。**不得**伪造独立试验，**不得**把未运行的检查项记为通过。
